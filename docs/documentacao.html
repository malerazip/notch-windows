Visão geral

O Projeto Notch é uma pílula preta que fica no centro do topo da tela. Com o notch fechado, ela mostra o que está tocando (ou a bateria), barras de áudio, o microfone e, quando estiver ligada, a webcam. Ao clicar, o notch abre e vira um painel com páginas de ferramentas: música, letra sincronizada, Pomodoro, lembrete de água, tarefas, prateleira de arquivos e novidades do seu site. Quando algo acontece (bateria fraca, hora de beber água, lançamento no site), ela se estica e mostra um alerta com botões.

Ele nasceu como substituto do Nusa, um app parecido em inglês e de código fechado. O autor do Nusa abandonou o projeto e não dava para acrescentar funções nele. O Projeto Notch refaz tudo o que o Nusa fazia, em português, e foi construído desde o início para aceitar ferramentas novas (plugins) e se conectar ao seu site.

O que dá para fazer com o notch

Ferramentas (páginas)

Tocando Agora

Controla a música de qualquer player (Spotify, YouTube no navegador, Deezer, Apple Music, VLC...): capa, título, artista, play/pause, avançar, voltar e barra de progresso clicável para pular.

Letra da Música

Letra sincronizada: a linha atual em destaque, a anterior e a próxima. Se não houver versão sincronizada, mostra a letra simples. Fonte: LRCLIB, gratuito e sem cadastro.

Timer Pomodoro

Ciclos de foco e pausa (25/5/15 min, ajustáveis), pausa longa a cada 4 focos, alerta com som no fim e contagem regressiva visível na pílula.

Lembrete de Água

Meta diária, garrafa e dose por gole. Na tela Lembretes você escolhe de quanto em quanto tempo ser lembrado (Auto, 30 min, 45 min, 1 h, 1h30, 2 h) e em que horário. Avisa quando a garrafa deve estar vazia e mostra o histórico por hora.

Lista de Tarefas

Adicionar, editar, concluir e excluir tarefas, com horário opcional. Na hora marcada aparece um alerta com "Concluir" e "+10 min".

Prateleira de Arquivos

Arraste arquivos, pastas, links ou textos para o notch. Eles ficam guardados até você arrastá-los para outro lugar (e-mail, WhatsApp Web, outra pasta) ou abri-los com um clique.

Novidades do Site

Consulta seu site de tempos em tempos e avisa quando algo novo é publicado, com um botão para abrir. Aceita JSON, RSS e Atom.

Botão do microfone

Sempre visível no canto direito da pílula: verde = ligado, vermelho cortado = mudo, cinza = sem microfone. Um clique muta/libera o microfone do Windows (vale para Teams, Zoom, Meet, WhatsApp) sem abrir o painel. O estado é conferido a cada segundo, então mudanças feitas em outros apps ou no próprio headset aparecem na hora. Também fica no cabeçalho do painel e no menu.

Indicador da webcam

Quando algum programa está usando a webcam (Teams, Zoom, Meet, Discord, app Câmera...), um ícone verde de câmera aparece ao lado do microfone. Com a webcam desligada, nenhum ícone. Passe o mouse para ver qual programa está usando.

Modo gamer

Some com o notch por completo por 15 min, 30 min, 1 h, 2 h ou até você desativar pelo ícone da bandeja. Avisos importantes esperam o notch voltar. Reiniciar ou desligar o PC sempre volta ao normal.

Cotação do Dia (plugin)

Exemplo de ferramenta externa: dólar, euro e bitcoin com variação do dia. Serve de modelo para criar as suas.

Comportamentos inteligentes

  • Some em tela cheia: filmes, jogos e apresentações em tela cheia escondem o notch automaticamente. Para sumir por um tempo mesmo sem tela cheia, use o modo gamer.
  • Abre só com clique: passar o mouse por cima não abre o notch (dá para mudar no menu, em "Abrir ao passar o mouse").
  • Largura que se ajusta: o notch fechado é estreito (~100 px) e só alarga quando precisa mostrar algo a mais, como a contagem do Pomodoro ou o ícone da webcam.
  • Não rouba o foco: clicar no notch não tira o foco da janela onde você está digitando (exceto ao digitar dentro dele).
  • Clique atravessa: fora da pílula, os cliques passam para as janelas de baixo.
  • Barras de áudio de verdade: em formato de onda, reagem ao nível real do som com ganho automático, então até uma transmissão com som baixo faz as barras dançarem. Ficam baixas e cinzas quando nada toca.
  • Fila de alertas: vários avisos seguidos entram em fila; avisos repetidos (volume, Caps Lock) só atualizam o atual.
  • Resistente a erros: se uma ferramenta ou plugin falhar, o resto continua funcionando e o erro vai para o log.
  • Instância única: abrir o app duas vezes não cria dois notches.

A criação: do Nusa ao Projeto Notch

  1. Análise do Nusa com a ferramenta REA. O NusaSetup.zip trazia um instalador Inno Setup 6.7 (Delphi), sem assinatura digital, de um autor identificado só como "Rama". Depois de instalado, o programa era um único nusa.exe de 900 KB escrito em Rust, desenhado com Direct2D/DirectComposition.
  2. Mapeamento das funções. Lendo os textos e as APIs do Windows usadas pelo executável, apareceram as funções: controles de mídia do Windows (música), LRCLIB (letras), Pomodoro, lembrete de água, tarefas, prateleira (%LOCALAPPDATA%\Nusa\Shelf), bateria, rede, Bluetooth, Caps Lock, leitura das notificações do Windows e inicialização automática pelo registro. Os dados ficavam em .txt chave=valor.
  3. Conclusão: não dava para estender. Não havia sistema de plugins, scripts nem código-fonte, e o autor abandonou o projeto. A recomendação foi recriar o app do zero, já pensado para receber ferramentas novas.
  4. Referência visual. Com o Nusa aberto, foram tiradas capturas do painel: fundo preto, cantos arredondados, título em duas cores (branco + azul), cabeçalho com bateria, data, hora e barras de áudio, botões em pílula e pontinhos de navegação.
  5. Escolha da tecnologia. O plano inicial era Tauri (Rust + HTML), mas o PC não tinha as ferramentas de compilação de Rust e C++ (de 6 a 8 GB). Para um app só de Windows, .NET 10 + WPF se mostrou melhor: acesso direto às APIs do Windows, leve e com o runtime já instalado. Bastou instalar o .NET 10 SDK (~250 MB) pelo winget.
  6. Arquitetura extensível primeiro. Antes das telas, foi criado o Notch.Sdk, o contrato que todas as ferramentas seguem. Assim as ferramentas internas e os plugins usam exatamente o mesmo mecanismo.
  7. Construção e testes reais. O app foi compilado sem erros nem avisos e testado no PC: alerta de boas-vindas, lembrete de água (clique em "Adiar"), música detectada no YouTube, todas as páginas, Pomodoro na pílula, menu, plugin carregado e conexão com um feed de verdade (com simulação de item novo). Ajustes visuais foram feitos a partir das capturas.
  8. Ajustes de uso, um a um. Depois da primeira versão: botão de microfone sempre visível (verde/vermelho), notch fechado sem hora e mais estreito, abrir só com clique, barras de áudio no estilo do Nusa com ganho automático, tela de lembretes de água com intervalo escolhido, modo gamer e indicador da webcam. Cada mudança foi testada no PC antes de seguir.

Arquitetura

O código está dividido em três partes:

  • src/Notch.Sdk: biblioteca pequena com o contrato das ferramentas (INotchModule, INotchHost, NotchAlert) e os componentes visuais (Ui, NotchTheme, Glyphs). Não depende do app.
  • src/Notch.App: o aplicativo. A janela (NotchWindow) implementa INotchHost, ou seja, oferece alertas, armazenamento, internet e navegação para as ferramentas. Os serviços conversam com o Windows; os módulos são as páginas.
  • plugins/: ferramentas externas. Cada plugin é uma DLL que referencia só o Notch.Sdk.

Fluxo de inicialização

  1. App.OnStartup garante uma única instância (mutex), define o idioma pt-BR, cria as pastas de dados e instala o tratamento global de erros.
  2. NotchWindow cria os serviços, monta a pílula e as três camadas (notch fechado, alerta, notch aberto).
  3. LoadModules registra as 7 ferramentas internas, carrega os plugins da pasta e chama Start(host) em cada uma. Se uma falhar, ela é removida e o erro vai para o log.
  4. Ao carregar a janela: inicia o monitor do sistema, conecta aos controles de mídia, liga as notificações (se configurado), cria o ícone da bandeja e, na primeira execução, mostra a mensagem de boas-vindas e ativa "Iniciar com o Windows".

A janela do notch

A janela é transparente, sem bordas, sempre no topo e invisível na barra de tarefas e no Alt+Tab. Dentro dela há uma única Border preta (a "concha") que muda de tamanho. Como a janela usa transparência por pixel, as áreas transparentes deixam o clique passar para as janelas de baixo: só a pílula é clicável.

Os três estados

Nesta documentação: notch fechado (ou compactado) é a pílula pequena parada no topo, funcionando só com os ícones; notch aberto (ou expandido) é quando ele abre o painel com as ferramentas; e alerta é quando a pílula se estica por alguns segundos para avisar algo. No código, eles se chamam State.Compact, State.Expanded e State.Alert.

  • Animação: largura e altura animam juntas. Para crescer, usa uma curva com leve "quique" (BackEase, 460 ms); para encolher, uma curva suave (CubicEase, 320 ms). O conteúdo troca com um esmaecimento cruzado.
  • Cantos: só os de baixo são arredondados (a pílula "sai" da borda da tela). O raio cresce com o tamanho: ~14 px, 24 px e 30 px.
  • Sem roubar o foco: o estilo WS_EX_NOACTIVATE impede que a janela ganhe foco ao ser clicada. Quando uma caixa de texto precisa do teclado, o app chama RequestKeyboardFocus() para ativá-la de propósito.
  • Tela cheia: a cada 1,5 s, o app verifica se a janela em primeiro plano ocupa a tela toda. Se ocupar, o notch desaparece com um esmaecimento e para de receber cliques.
  • Modo gamer: usa o mesmo mecanismo de esconder da tela cheia, mas ligado por você e com timer opcional. O estado fica só na memória (não é salvo em arquivo), por isso reiniciar ou desligar o PC sempre volta ao normal.
  • Largura do notch fechado: as colunas se ajustam ao conteúdo visível: ~100 px normal, ~146 px com Pomodoro, +18 px com a webcam ligada, 56 px no modo minimalista.
  • Sempre por cima: no mesmo ciclo, o app reforça a posição "sempre no topo", já que a barra de tarefas às vezes a toma.
  • Páginas: as ferramentas habilitadas são ordenadas pelo campo Order. Cada página é criada só na primeira vez que é aberta e depois reaproveitada. A troca desliza 28 px na direção da navegação.
  • Arrastar e soltar: quando arquivos são arrastados sobre a pílula, o notch abre direto na Prateleira; ao soltar, os arquivos vão para ShelfModule.Accept.

Alertas

Qualquer parte do app (ou um plugin) chama host.ShowAlert(new NotchAlert(...)). O alerta tem:

CampoUso
Title, MessageTexto principal (negrito) e secundário.
Glyph / ImageÍcone da fonte Segoe Fluent Icons, ou uma imagem (capa, logo do app).
AccentCor do ícone e da barra.
Progress0 a 1 para mostrar uma barra (volume, brilho, bateria).
DurationQuanto tempo fica visível (padrão: 4 s).
KeyAlertas com a mesma chave se substituem (ex.: apertar volume várias vezes atualiza o mesmo alerta).
ActionsAté dois botões (ex.: "Bebi" / "Adiar"). O primeiro aparece em azul.
OnClickAção ao clicar no corpo do alerta. Sem ela, o clique abre o painel.

Regras da fila

  • Os alertas entram numa fila e aparecem um de cada vez.
  • Alertas com Key (volume, Caps Lock, rede...) atualizam o alerta atual em vez de entrar na fila, e são descartados se o painel estiver aberto.
  • Os outros (água, tarefa, site) esperam o painel fechar e aparecem em seguida.
  • Com o mouse sobre o alerta, o tempo para de correr; ao sair, sobra 1,5 s.
  • Em tela cheia ou no modo gamer, alertas rápidos são descartados e os importantes esperam o notch voltar.
host.ShowAlert(new NotchAlert("Hora de beber água", "Beba 250 ml · 0,5 de 2,0 L hoje")
{
    Glyph = Glyphs.Drop,
    Accent = NotchTheme.Accent,
    Duration = TimeSpan.FromSeconds(12),
    Actions = [new NotchAlertAction("Bebi", Drink), new NotchAlertAction("Adiar", Snooze)],
});

As ferramentas por dentro

Tocando Agora (MusicModule + MediaService)

Usa os controles de mídia do Windows (GlobalSystemMediaTransportControlsSessionManager), os mesmos que aparecem no painel de volume do Windows 11. Assim funciona com qualquer player que se integre ao Windows, sem precisar de login no Spotify. O serviço acompanha a sessão atual e reage a três eventos: mudança de faixa (título, artista, capa), de reprodução (tocando/pausado) e de linha do tempo (posição). A posição exibida é calculada como última posição informada + tempo decorrido desde então, porque os players só informam a posição de vez em quando. Clicar na barra chama TryChangePlaybackPositionAsync.

Letra da Música (LyricsModule + LyricsService)

  1. Ao mudar de faixa, limpa o título (remove "(feat. ...)", "- Remastered 2011", "(Ao Vivo)" etc.).
  2. Tenta a busca exata no LRCLIB (/api/get com artista, título, álbum e duração).
  3. Se não achar, usa a busca aproximada (/api/search) e escolhe o resultado com letra sincronizada e duração mais próxima.
  4. Converte o formato LRC ([01:23.45] texto) numa lista ordenada de linhas com tempo.
  5. A cada 150 ms (só com a página visível), encontra a última linha cujo tempo ≤ posição + 250 ms e destaca essa linha com um esmaecimento.

Os resultados ficam em cache durante a sessão. Erros de rede não entram no cache, para tentar de novo depois.

Timer Pomodoro (PomodoroModule)

É uma máquina de estados: Foco → Pausa curta → Foco → ... → Pausa longa (a cada 4 focos completos). O tempo final é guardado como um horário absoluto (_endsAt), então a contagem continua precisa mesmo com o painel fechado. Ao terminar: troca o modo, toca um som do sistema e mostra um alerta com o botão "Iniciar". Os tempos ficam em pomodoro.txt. Enquanto roda, a pílula mostra a contagem com o ícone do modo (laranja no foco, verde na pausa).

Lembrete de Água (WaterModule)

Na tela Lembretes você escolhe o intervalo ("A cada": Auto, 30 min, 45 min, 1 h, 1h30, 2 h) e o horário. Ao trocar o intervalo, a contagem recomeça daquele momento. A linha de status sempre explica o que está acontecendo: "a cada 1 h · próximo 20:56", "fora do horário (08:00–18:00)" ou "lembretes desligados". O botão Testar mostra o alerta de exemplo. No modo Auto, o intervalo distribui a meta ao longo do horário:

intervalo = (fim − início) ÷ ⌈meta ÷ dose⌉        (mínimo de 15 min)
próximo   = máx(último gole ou lembrete, início) + intervalo

Exemplo: das 08:00 às 18:00 (600 min), meta de 2.000 ml e dose de 250 ml → 8 lembretes, um a cada 75 min. Cada "Beber" soma a dose ao total, desconta da garrafa e registra no histórico por hora. Quando a garrafa deveria estar vazia, o alerta muda para "Hora de reabastecer". "Adiar" empurra o lembrete em 10 min. À meia-noite o dia reinicia, e o primeiro lembrete só vem um intervalo depois de ligar o PC. Clique no anel para alternar com o gráfico por hora.

Lista de Tarefas (TodoModule)

Cada tarefa é uma linha de todo.txt no formato feito|diaFeito|hora|diaAvisado|título. A cada 15 s, o módulo procura tarefas pendentes cuja hora já passou e que ainda não foram avisadas hoje. Concluídas de dias anteriores saem da lista ao abrir o app. No formulário, Enter salva e Esc cancela, e há atalhos "+30 min", "+1 h" e "Sem hora". O horário aceita formatos como 14:30, 9:05, 14h30 ou 14.

Prateleira de Arquivos (ShelfModule)

Arquivos e pastas soltos são copiados para %LOCALAPPDATA%\ProjetoNotch\Shelf numa thread separada, sem travar a tela. Nomes repetidos ganham " (2)", " (3)"... Links viram atalhos .url e textos viram .txt. Cada item mostra o ícone do Windows (ou uma miniatura, se for imagem). Clicar abre o item; arrastar inicia um arrastar-e-soltar com o arquivo real; o "×" exclui. "Limpar" esvazia tudo.

Novidades do Site (SiteModule)

Veja a seção Conectar seu site. Internamente, a busca (CheckAsync) é separada da leitura (Parse). Os IDs já vistos ficam em site.txt (até 300), e a primeira consulta apenas memoriza os itens, para não disparar avisos antigos. Até 3 novidades geram alertas individuais; mais que isso gera um resumo ("5 novos itens").

Diferente do Nusa, que instalava um gancho global de teclado (SetWindowsHookEx), o Projeto Notch não intercepta o que você digita. Caps Lock e idioma são lidos só como estado, e o volume vem do próprio Windows. Isso também evita desconfiança de antivírus.

Conectar seu site

Na página Novidades do Site, cole o endereço público de um arquivo de novidades e escolha o intervalo (5, 15, 30 ou 60 min). Clique em Salvar e testar. Na primeira consulta o notch só memoriza o que já existe; a partir daí, cada item com id novo gera um alerta com o botão Abrir.

Formato 1: JSON simples (recomendado)

{
  "items": [
    {
      "id": "lancamento-42",
      "titulo": "Nova taxa para consignado INSS",
      "descricao": "A partir de hoje, taxa de 1,66% a.m.",
      "url": "https://seusite.com.br/noticias/42",
      "data": "2026-10-25T10:00:00-03:00"

Formato 2: RSS ou Atom

Se o site é WordPress, Blogger, Wix, Medium ou similar, ele já tem um feed. Use, por exemplo, https://seusite.com.br/feed. São lidos <item> (RSS) e <entry> (Atom), com guid/id, title, link, description/summary e pubDate/published.

Formato 3: JSON Feed

O padrão jsonfeed.org funciona direto. Ele foi usado nos testes.

Como publicar o arquivo no seu site

  • Site estático: suba um novidades.json e atualize-o a cada lançamento, colocando o item novo no topo.
  • Com painel/servidor: crie uma rota que gere o JSON a partir do banco. Exemplo em PHP:
<?php // novidades.php
header('Content-Type: application/json; charset=utf-8');
$itens = $pdo->query("SELECT id, titulo, descricao, url, publicado_em AS data
                      FROM lancamentos ORDER BY publicado_em DESC LIMIT 20")->fetchAll(PDO::FETCH_ASSOC);
echo json_encode(['items' => $itens], JSON_UNESCAPED_UNICODE);

Endereço protegido

Se o endereço exigir autenticação, preencha Token. O notch envia Authorization: Bearer <token>; no servidor, basta comparar esse cabeçalho com o seu segredo.

Evolução: avisos instantâneos

Hoje a consulta é periódica (polling), o que é simples, funciona atrás de qualquer firewall e não exige servidor especial. Para avisos no mesmo segundo, o próximo passo é trocar CheckAsync por uma conexão contínua (Server-Sent Events ou WebSocket). Como a leitura (Parse) e a interface são separadas, essa troca não mexe no resto do módulo.

Criar ferramentas novas (plugins)

Uma ferramenta é uma classe pública que implementa INotchModule. As ferramentas internas usam o mesmo contrato, então um plugin pode fazer tudo o que elas fazem.

Passo a passo

  1. Crie o projeto copiando plugins\Exemplo.Cotacao (por exemplo, para plugins\MinhaFerramenta) e renomeie o .csproj.
  2. Escreva a classe que implementa INotchModule (veja o modelo abaixo).
  3. Compile e instale direto na pasta de plugins: 
    dotnet build plugins\MinhaFerramenta -c Release -o "$env:APPDATA\ProjetoNotch\plugins\MinhaFerramenta"
  4. Reinicie o notch (menu → Sair, depois abra de novo). A página nova aparece no carrossel, e no menu "Ferramentas" dá para ligar e desligar.

Modelo mínimo

using System.Windows;
using Notch.Sdk;

public sealed class MinhaFerramenta : INotchModule
{
    public string Id => "minha-ferramenta";     // único e estável
    public string Title => "Minha";             // parte branca do título
    public string TitleAccent => "Ferramenta";  // parte azul
    public int Order => 90;                     // posição no carrossel

    private INotchHost _host = null!;
    private KeyValueFile _dados = null!;

    public void Start(INotchHost host)
    {
        _host = host;
        _dados = host.OpenStore("minha-ferramenta");   // %APPDATA%\ProjetoNotch\minha-ferramenta.txt
    }

    public FrameworkElement CreateView()
    {
        var contador = Ui.Text($"Cliques: {_dados.GetInt("cliques", 0)}", 16, FontWeights.Bold);
        return Ui.Column(10,
            contador,
            Ui.Row(8,
                Ui.Button(Glyphs.Add, "Somar", () =>
                {
                    _dados.Set("cliques", _dados.GetInt("cliques", 0) + 1);
                    _dados.Save();
                    contador.Text = $"Cliques: {_dados.GetInt("cliques", 0)}";
                }, NotchTheme.AccentDeep),
                Ui.Button(Glyphs.Bell, "Alerta", () =>
                    _host.ShowAlert(new NotchAlert("Funcionou!", "Meu primeiro plugin") { Accent = NotchTheme.Green }))));
    }

    public void Stop() { }
}

Privacidade e segurança

  • Nada é enviado para servidores próprios. As únicas conexões são: lrclib.net (título e artista da música, para buscar a letra), o seu site (se configurado) e as APIs que cada plugin usa (o exemplo usa a AwesomeAPI).
  • Sem gancho de teclado: o app não lê o que você digita.
  • Webcam: o notch nunca abre a câmera. Ele só recebe do Windows o aviso de que algum programa começou ou parou de usá-la.
  • Notificações do Windows ficam desligadas por padrão. Ao ligar, o Windows pede sua permissão, e elas são só exibidas no notch, sem gravação.
  • Sem administrador: roda com as permissões do seu usuário; a inicialização automática usa só o registro do seu usuário.
  • Dados locais: todos os arquivos ficam no seu perfil (%APPDATA% e %LOCALAPPDATA%).
  • Token do site: é guardado em texto puro em site.txt. Use um token só de leitura.

/// <summary>Arquivo de texto simples no formato chave=valor (um por linha).</summary>
public sealed class KeyValueFile
{
    private readonly Dictionary<string, string> _values = new(StringComparer.OrdinalIgnoreCase);

    public string Path { get; }

    public KeyValueFile(string path)
    {
        Path = path;
        try
        {
            if (!File.Exists(path)) return;
            foreach (var line in File.ReadAllLines(path))
            {
                var i = line.IndexOf('=');
                if (i > 0) _values[line[..i].Trim()] = line[(i + 1)..];
            }
        }
        catch (IOException) { }
    }

    public string Get(string key, string fallback = "") =>
        _values.TryGetValue(key, out var v) ? v : fallback;

    public int GetInt(string key, int fallback) =>
        int.TryParse(Get(key), NumberStyles.Integer, CultureInfo.InvariantCulture, out var v) ? v : fallback;

    public bool GetBool(string key, bool fallback) =>
        _values.TryGetValue(key, out var v) ? v == "1" : fallback;

    public void Set(string key, string value) => _values[key] = value;
    public void Set(string key, int value) => _values[key] = value.ToString(CultureInfo.InvariantCulture);
    public void Set(string key, bool value) => _values[key] = value ? "1" : "0";

    public void Save()
    {
        try
        {
            Directory.CreateDirectory(System.IO.Path.GetDirectoryName(Path)!);
            File.WriteAllLines(Path, _values.Select(kv => $"{kv.Key}={kv.Value}"));
        }
        catch (IOException) { }
    }
}

    private void LoadModules()
    {
        _modules.AddRange(new INotchModule[]
        {

                _modules.Remove(m);
            }
        }

    private void RebuildPages()
    {
        var current = _pages.Count > 0 && _pageIndex < _pages.Count ? _pages[_pageIndex].Module.Id : null;
        var disabled = DisabledModules();
        var views = _pages.ToDictionary(p => p.Module.Id, p => p.View);
        _pages.Clear();
        foreach (var m in _modules.Where(m => !disabled.Contains(m.Id)).OrderBy(m => m.Order))
            _pages.Add(new Page(m) { View = views.GetValueOrDefault(m.Id) });
        var idx = current == null ? 0 : _pages.FindIndex(p => p.Module.Id == current);
        _pageIndex = Math.Max(0, idx);
        if (_state == State.Expanded) SetPage(_pageIndex, animate: false);
    }

    private HashSet<string> DisabledModules() =>
        _settings.Get("disabled").Split(',', StringSplitOptions.RemoveEmptyEntries).ToHashSet();

    private void WireEvents()
    {
        _shell.MouseEnter += (_, _) =>
        {
            _leaveTimer.Stop();
            if (_state == State.Alert) _alertTimer.Stop();       // não some enquanto o mouse está em cima
            // por padrão o notch só abre com clique; abrir ao passar o mouse é uma opção do menu
            else if (_state == State.Compact && OpenOnHover && !_compactMic.IsMouseOver) _hoverTimer.Start();
        };
        _shell.MouseLeave += (_, _) =>
        {
            _hoverTimer.Stop();
            if (_state == State.Alert)
            {
                _alertTimer.Interval = TimeSpan.FromSeconds(1.5);
                _alertTimer.Start();
            }
            else if (_state == State.Expanded) _leaveTimer.Start();
        };
        _shell.MouseRightButtonUp += (_, e) => { ShowTrayMenuAtCursor(); e.Handled = true; };

        _hoverTimer.Tick += (_, _) =>
        {
            _hoverTimer.Stop();
            if (OpenOnHover && _shell.IsMouseOver && !_compactMic.IsMouseOver && _state == State.Compact) Expand();
        };

        _leaveTimer.Tick += (_, _) =>
        {
            _leaveTimer.Stop();
            if (_state != State.Expanded || _shell.IsMouseOver || _dragging) return;
            if (IsActive && Keyboard.FocusedElement is TextBox) return; // digitando: só fecha ao clicar fora
            Collapse();
        };
        Deactivated += (_, _) =>
        {
            if (_state == State.Expanded && !_shell.IsMouseOver && !_dragging) Collapse();
        };
        _alertTimer.Tick += (_, _) =>
        {
            _alertTimer.Stop();
            _currentAlert = null;
            if (_alerts.Count > 0) ShowNextAlert();
            else SetState(State.Compact);
        };

        // arrastar arquivos para o notch abre a prateleira
        _shell.DragEnter += (_, e) =>
        {
            _dragging = true;
            _leaveTimer.Stop();
            var shelf = _pages.FindIndex(p => p.Module == _shelf);
            if (shelf >= 0)
            {
                if (_state != State.Expanded) Expand();
                if (_pageIndex != shelf) SetPage(shelf);
            }
            e.Effects = shelf >= 0 ? DragDropEffects.Copy : DragDropEffects.None;
            e.Handled = true;
        };
        _shell.DragOver += (_, e) =>
        {
            e.Effects = _pages.Any(p => p.Module == _shelf) ? DragDropEffects.Copy : DragDropEffects.None;
            e.Handled = true;
        };
        _shell.DragLeave += (_, _) =>
        {
            _dragging = false;
            _leaveTimer.Start();
        };
        _shell.Drop += (_, e) =>
        {
            _dragging = false;
            if (_pages.Any(p => p.Module == _shelf)) _shelf.Accept(e.Data);
            e.Handled = true;
            _leaveTimer.Start();
        };

        _clockTimer.Tick += (_, _) => { UpdateClock(); UpdateCompact(); _audio.SyncMic(); UpdateCamera(); };
        _clockTimer.Start();
        _guardTimer.Tick += (_, _) => GuardTick();
        _guardTimer.Start();

        _media.Changed += UpdateCompact;
        _pomodoro.StateChanged += UpdateCompact;
        _status.BatteryChanged += () =>
        {
            _headerBattery.Update(_status.BatteryPercent, _status.Charging);
            _compactBattery.Update(_status.BatteryPercent, _status.Charging);
            _headerBattery.Visibility = _status.HasBattery ? Visibility.Visible : Visibility.Collapsed;
            UpdateCompact();
        };
        _audio.MicChanged += OnMicChanged;
        OnMicChanged(_audio.MicMuted);
        _audio.VolumeChanged += (volume, muted) =>
        {
            if (!Setting("alerts.volume")) return;
            ShowAlert(new NotchAlert("Volume", muted ? "Mudo" : $"{Math.Round(volume * 100)}%")
            {
                Glyph = muted || volume < 0.005 ? Glyphs.Mute : Glyphs.Volume,
                Accent = NotchTheme.Text,
                Progress = muted ? 0 : volume,
                Duration = TimeSpan.FromSeconds(1.6),
                Key = "volume",
            });
        };

        SourceInitialized += (_, _) =>
        {
            _hwnd = new WindowInteropHelper(this).Handle;
            var ex = Native.GetWindowLongPtr(_hwnd, Native.GWL_EXSTYLE);
            Native.SetWindowLongPtr(_hwnd, Native.GWL_EXSTYLE, ex | Native.WS_EX_TOOLWINDOW | Native.WS_EX_NOACTIVATE);
        };
        Loaded += async (_, _) =>
        {
            _status.Start();
            await _media.StartAsync();
            if (Setting("winnotif", false)) await _winNotif.StartAsync();
            CreateTray();
            if (!_settings.GetBool("welcomed", false))
            {
                _settings.Set("welcomed", true);
                _settings.Save();
                Autostart.Set(true);
                ShowAlert(new NotchAlert("Olá! Eu sou o seu notch 👋", "Clique aqui em cima para abrir")
                {
                    Glyph = Glyphs.Info,
                    Accent = NotchTheme.Accent,
                    Duration = TimeSpan.FromSeconds(7),
                });
            }
        };
        Microsoft.Win32.SystemEvents.DisplaySettingsChanged += (_, _) => Dispatcher.BeginInvoke(Reposition);
        DpiChanged += (_, _) => Reposition();
    }

    /// <param name="showAlert">false quando o clique foi no ícone da pílula: o próprio ícone já mostra o estado.</param>

    private void OnMicChanged(bool muted)
    {
        // verde = ligado (estão te ouvindo) · vermelho cortado = mudo · cinza = sem microfone
        var glyph = !_audio.HasMic || muted ? Glyphs.MicOff : Glyphs.Microphone;
        var color = !_audio.HasMic ? NotchTheme.TextDim : muted ? NotchTheme.Red : NotchTheme.Green;
        var tip = !_audio.HasMic ? "Nenhum microfone conectado"
            : muted ? "Microfone MUDO · clique para ativar" : "Microfone LIGADO · clique para mutar";
        foreach (var icon in new[] { (TextBlock)_micButton.Child, _compactMicIcon })
        {
            icon.Text = glyph;
            icon.Foreground = color;
        }
        _micButton.ToolTip = tip;
        _compactMic.ToolTip = tip;

        // alerta só quando o estado muda de verdade (não ao trocar de fone, por exemplo)
        // (com o painel aberto, alertas com Key são ignorados: o próprio botão já mostra o estado)
        if (_lastMicMuted.HasValue && _lastMicMuted != muted && !_quietMicChange)
        {
            ShowAlert(new NotchAlert(muted ? "Microfone mudo" : "Microfone ativado", muted ? "Ninguém está te ouvindo" : "Você está sendo ouvido")
            {
                Glyph = muted ? Glyphs.MicOff : Glyphs.Microphone,
                Accent = muted ? NotchTheme.Red : NotchTheme.Green,
                Duration = TimeSpan.FromSeconds(1.8),
                Key = "mic",
            });
        }
        _lastMicMuted = muted;
        UpdateCompact();
    }

    private void SetState(State state, bool animate = true)
    {
        _state = state;
        double w, h, radius;
        switch (state)
        {
            case State.Expanded:
                (w, h, radius) = (ExpandedW, ExpandedH, 30);
                break;
            case State.Alert:
                w = _currentAlert?.Actions.Count > 0 ? 430 : 370;
                (h, radius) = (AlertH, 24);
                _alertLayer.Width = w;
                break;
            default:
                (w, h) = CompactSize;
                _appliedCompactSize = (w, h);
                radius = h / 2.2;
                _compactLayer.Height = h;
                break;
        }
        _shell.CornerRadius = new CornerRadius(0, 0, radius, radius);
        Animate(w, h, animate, bouncy: state != State.Compact);
        ShowLayer(state switch { State.Expanded => _expandedLayer, State.Alert => _alertLayer, _ => _compactLayer }, animate);
        _compactMascot.Happy = false;
        UpdateCompact();
    }

    private void Animate(double w, double h, bool animate, bool bouncy)
    {
        if (!animate)
        {
            _shell.BeginAnimation(WidthProperty, null);
            _shell.BeginAnimation(HeightProperty, null);
            _shell.Width = w;
            _shell.Height = h;
            return;
        }
        var duration = TimeSpan.FromMilliseconds(bouncy ? 460 : 320);
        IEasingFunction ease = bouncy
            ? new BackEase { Amplitude = 0.28, EasingMode = EasingMode.EaseOut }
            : new CubicEase { EasingMode = EasingMode.EaseOut };
        _shell.BeginAnimation(WidthProperty, new DoubleAnimation(w, duration) { EasingFunction = ease });
        _shell.BeginAnimation(HeightProperty, new DoubleAnimation(h, duration) { EasingFunction = ease });
    }

    private void ShowLayer(Grid target, bool animate)
    {
        foreach (var layer in new[] { _compactLayer, _alertLayer, _expandedLayer })
        {
            var show = layer == target;
            layer.IsHitTestVisible = show;
            if (!animate)
            {
                layer.BeginAnimation(OpacityProperty, null);
                layer.Opacity = show ? 1 : 0;
                layer.Visibility = show ? Visibility.Visible : Visibility.Collapsed;
                continue;
            }
            if (show)
            {
                layer.Visibility = Visibility.Visible;
                layer.BeginAnimation(OpacityProperty, new DoubleAnimation(0, 1, TimeSpan.FromMilliseconds(260)) { BeginTime = TimeSpan.FromMilliseconds(90) });
            }
            else if (layer.Visibility == Visibility.Visible)
            {
                var fade = new DoubleAnimation(0, TimeSpan.FromMilliseconds(110));
                fade.Completed += (_, _) => { if (!layer.IsHitTestVisible) layer.Visibility = Visibility.Collapsed; };
                layer.BeginAnimation(OpacityProperty, fade);
            }
        }
    }

    }

    private void SetPage(int index, bool animate = true)
    {
        if (_pages.Count == 0) return;
        var direction = index > _pageIndex ? 1 : -1;
        index = ((index % _pages.Count) + _pages.Count) % _pages.Count;
        var page = _pages[index];
        if (page.View == null)
        {
            try { page.View = page.Module.CreateView(); }
            catch (Exception ex)
            {
                Paths.WriteLog($"Página {page.Module.Id} falhou: {ex}");
                page.View = Ui.Text("Esta ferramenta encontrou um erro. Veja o log.", 12, null, NotchTheme.Red);
            }
        }
        var changed = _pageIndex != index || _pageHost.Content != page.View;
        _pageIndex = index;
        _pageHost.Content = page.View;
        _title.Inlines.Clear();
        _title.Inlines.Add(new Run(page.Module.Title) { Foreground = NotchTheme.Text });
        if (page.Module.TitleAccent.Length > 0)
            _title.Inlines.Add(new Run(" " + page.Module.TitleAccent) { Foreground = NotchTheme.Accent });
        UpdateDots();
        if (_settings.Get("page") != page.Module.Id)
        {
            _settings.Set("page", page.Module.Id);
            _settings.Save();
        }
        if (animate && changed)
        {
            var tt = (TranslateTransform)_pageHost.RenderTransform;
            var ease = new CubicEase { EasingMode = EasingMode.EaseOut };
            tt.BeginAnimation(TranslateTransform.XProperty, new DoubleAnimation(28 * direction, 0, TimeSpan.FromMilliseconds(260)) { EasingFunction = ease });
            _pageHost.BeginAnimation(OpacityProperty, new DoubleAnimation(0, 1, TimeSpan.FromMilliseconds(220)));
        }
    }

    private void UpdateDots()
    {
        _dots.Children.Clear();
        for (var i = 0; i < _pages.Count; i++)
        {
            var active = i == _pageIndex;
            var index = i;
            var dot = new Border
            {
                Width = active ? 14 : 5,
                Height = 5,
                CornerRadius = new CornerRadius(2.5),
                Background = active ? NotchTheme.Text : NotchTheme.TextFaint,

                Cursor = Cursors.Hand,
                ToolTip = _pages[i].Module.Title + " " + _pages[i].Module.TitleAccent,
            };
            // área de clique maior que o pontinho
            var hit = new Border { Background = Brushes.Transparent, Padding = new Thickness(0, 5, 0, 5), Child = dot };
            hit.MouseLeftButtonUp += (_, e) => { SetPage(index); e.Handled = true; };
            _dots.Children.Add(hit);
        }
    }

    public void ShowAlert(NotchAlert alert)
    {
        if (!Dispatcher.CheckAccess())
        {
            Dispatcher.BeginInvoke(() => ShowAlert(alert));
            return;
        }
        // escondido (tela cheia ou modo gamer): avisos rápidos são descartados; os importantes esperam o notch voltar
        if (IsHidden && alert.Key != null) return;

        // mesmo tipo (volume, caps lock...): atualiza o alerta atual em vez de enfileirar
        if (alert.Key != null && _state == State.Alert && _currentAlert?.Key == alert.Key)
        {
            _currentAlert = alert;
            BuildAlert(alert);
            _alertTimer.Stop();
            _alertTimer.Interval = alert.Duration;
            if (!_shell.IsMouseOver) _alertTimer.Start();
            return;
        }
        if (alert.Key != null && _state == State.Expanded) return; // avisos rápidos não interrompem o painel aberto
        if (alert.Key != null)
        {
            // remove da fila versões antigas do mesmo aviso
            var rest = _alerts.Where(a => a.Key != alert.Key).ToList();
            _alerts.Clear();
            foreach (var a in rest) _alerts.Enqueue(a);
        }
        _alerts.Enqueue(alert);
        if (_state == State.Compact && !IsHidden) ShowNextAlert();
    }

    private void ShowNextAlert()
    {
        if (_alerts.Count == 0) return;
        var alert = _alerts.Dequeue();
        _currentAlert = alert;
        BuildAlert(alert);
        SetState(State.Alert);
        _alertTimer.Stop();
        _alertTimer.Interval = alert.Duration;
        if (!_shell.IsMouseOver) _alertTimer.Start();
    }

    private void DismissAlert()
    {
        _alertTimer.Stop();
        _currentAlert = null;
        if (_alerts.Count > 0) ShowNextAlert();
        else SetState(State.Compact);
    }

    private void BuildAlert(NotchAlert alert)
    {
        _alertLayer.Children.Clear();
        _alertLayer.ColumnDefinitions.Clear();
        _alertLayer.ColumnDefinitions.Add(new ColumnDefinition { Width = GridLength.Auto });
        _alertLayer.ColumnDefinitions.Add(new ColumnDefinition());
        _alertLayer.ColumnDefinitions.Add(new ColumnDefinition { Width = GridLength.Auto });
        _alertLayer.Background = Brushes.Transparent;
        _alertLayer.Cursor = Cursors.Hand;

        FrameworkElement icon;
        if (alert.Image != null)
            icon = new Border { Width = 38, Height = 38, CornerRadius = new CornerRadius(10), Background = new ImageBrush(alert.Image) { Stretch = Stretch.UniformToFill } };
        else
            icon = new Border
            {
                Width = 38,
                Height = 38,
                CornerRadius = new CornerRadius(19),
                Background = NotchTheme.Surface,
                Child = Ui.Icon(alert.Glyph, 16, alert.Accent ?? NotchTheme.Text),
            };
        icon.Margin = new Thickness(16, 0, 12, 0);
        icon.VerticalAlignment = VerticalAlignment.Center;
        _alertLayer.Children.Add(icon);

        var text = new StackPanel { VerticalAlignment = VerticalAlignment.Center, Margin = new Thickness(0, 0, 10, 0) };
        text.Children.Add(Ui.Text(alert.Title, 13.5, FontWeights.Bold));
        if (alert.Progress is { } p && alert.Actions.Count == 0)
        {
            var row = new Grid { Margin = new Thickness(0, 5, 0, 0) };
            row.ColumnDefinitions.Add(new ColumnDefinition());
            row.ColumnDefinitions.Add(new ColumnDefinition { Width = GridLength.Auto });
            var bar = Ui.ProgressBar(p, alert.Accent ?? NotchTheme.Text, 5);
            row.Children.Add(bar);
            var label = Ui.Text(alert.Message, 11, FontWeights.SemiBold, NotchTheme.TextDim);
            label.Margin = new Thickness(10, 0, 0, 0);
            Grid.SetColumn(label, 1);
            row.Children.Add(label);
            text.Children.Add(row);
        }
        else
        {
            text.Children.Add(Ui.Text(alert.Message, 11.5, null, NotchTheme.TextDim));
        }
        Grid.SetColumn(text, 1);
        _alertLayer.Children.Add(text);

using System.IO;
using System.Reflection;
using System.Runtime.Loader;
using Notch.Sdk;

namespace Notch.App.Core;

/// <summary>
/// Carrega plugins de %APPDATA%\ProjetoNotch\plugins\&lt;pasta&gt;\*.dll.
/// Cada pasta ganha seu próprio contexto de carregamento; Notch.Sdk e WPF são compartilhados com o app.
/// </summary>
internal static class PluginLoader
{
    public static List<INotchModule> Load(string pluginsDir)
    {
        var modules = new List<INotchModule>();
        if (!Directory.Exists(pluginsDir)) return modules;

        foreach (var dir in Directory.GetDirectories(pluginsDir))
        {
            foreach (var dll in Directory.GetFiles(dir, "*.dll"))
            {
                if (Path.GetFileName(dll).Equals("Notch.Sdk.dll", StringComparison.OrdinalIgnoreCase)) continue;
                try
                {
                    var context = new PluginContext(dll);
                    var assembly = context.LoadFromAssemblyPath(Path.GetFullPath(dll));
                    foreach (var type in assembly.GetExportedTypes())
                    {
                        if (type.IsAbstract || !typeof(INotchModule).IsAssignableFrom(type)) continue;
                        if (Activator.CreateInstance(type) is INotchModule module)
                        {
                            modules.Add(module);
                            Paths.WriteLog($"Plugin carregado: {module.Id} ({dll})");
                        }
                    }
                }
                catch (Exception ex) when (ex is BadImageFormatException or FileLoadException or ReflectionTypeLoadException or TypeLoadException or MissingMethodException or TargetInvocationException)
                {
                    Paths.WriteLog($"Falha ao carregar plugin {dll}: {ex.Message}");
                }
            }
        }
        return modules;
    }

    private sealed class PluginContext(string mainAssemblyPath) : AssemblyLoadContext(isCollectible: false)
    {
        private readonly AssemblyDependencyResolver _resolver = new(mainAssemblyPath);

        protected override Assembly? Load(AssemblyName name)
        {
            // Tipos compartilhados precisam vir do app, senão INotchModule não "casa".
            if (name.Name == "Notch.Sdk") return typeof(INotchModule).Assembly;
            // Reaproveita o que o app já carregou (WinRT, NAudio...) para não duplicar
            var shared = Default.Assemblies.FirstOrDefault(a => a.GetName().Name == name.Name);
            if (shared != null) return shared;
            var path = _resolver.ResolveAssemblyToPath(name);
            return path != null ? LoadFromAssemblyPath(path) : null;
        }
    }

    {

                {
                    var hasSynced = item.TryGetProperty("syncedLyrics", out var s) && s.ValueKind == JsonValueKind.String;
                    var d = item.TryGetProperty("duration", out var dd) && dd.ValueKind == JsonValueKind.Number ? dd.GetDouble() : 0;
                    var score = (hasSynced ? 0 : 1000) + (duration > TimeSpan.Zero ? Math.Abs(d - duration.TotalSeconds) : 0);
                    if (score < bestScore) { bestScore = score; best = item.Clone(); }
                }

                    synced.Add(new LyricLine(TimeSpan.FromSeconds(min * 60 + sec), text));
                }
            }

        }

                names.Add(p.ProcessName);

            catch (ArgumentException) { } // processo já fechou

        }

        var bootUtc = DateTime.UtcNow - TimeSpan.FromMilliseconds(Environment.TickCount64);
        foreach (var name in parent.GetSubKeyNames())

/// <summary>Base dos módulos internos: guarda o host e oferece um timer que só roda com a página visível.</summary>
internal abstract class ModuleBase : INotchModule
{

    public abstract string Id { get; }
    public abstract string Title { get; }
    public abstract string TitleAccent { get; }

    protected static void WhileVisible(FrameworkElement view, TimeSpan interval, Action tick)
    {
        var timer = new DispatcherTimer { Interval = interval };
        timer.Tick += (_, _) => tick();
        view.IsVisibleChanged += (_, _) =>
        {
            if (view.IsVisible) { tick(); timer.Start(); }
            else timer.Stop();
        };
    }

        t.TotalHours >= 1 ? $"{(int)t.TotalHours}:{t.Minutes:00}:{t.Seconds:00}" : $"{(int)t.TotalMinutes}:{t.Seconds:00}";
}

internal sealed class ShelfModule : ModuleBase
{

    public override string Id => "prateleira";

    private event Action? Changed;

    /// <summary>Recebe o que foi solto no notch (arquivos, pastas, links ou texto).</summary>
    public async void Accept(IDataObject data)
    {
        try
        {
            if (data.GetData(DataFormats.FileDrop) is string[] files)
            {
                await Task.Run(() =>
                {
                    foreach (var src in files) CopyIn(src);
                });
            }
            else if (data.GetData(DataFormats.UnicodeText) is string text && text.Trim().Length > 0)
            {
                text = text.Trim();
                if (Uri.TryCreate(text, UriKind.Absolute, out var uri) && (uri.Scheme == "http" || uri.Scheme == "https"))
                {
                    var name = SafeName(uri.Host + uri.AbsolutePath.TrimEnd('/').Replace('/', '-'));
                    File.WriteAllText(Unique(Path.Combine(Paths.Shelf, name + ".url")), $"[InternetShortcut]\r\nURL={uri}\r\n");
                }
                else
                {
                    var first = SafeName(new string(text.Take(30).ToArray()));
                    File.WriteAllText(Unique(Path.Combine(Paths.Shelf, (first.Length > 0 ? first : "texto") + ".txt")), text);
                }
            }
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            Host.ShowAlert(new NotchAlert("Não foi possível guardar", ex.Message) { Glyph = Glyphs.Folder, Accent = NotchTheme.Red });
        }
        Changed?.Invoke();
    }

    private static void CopyIn(string src)
    {
        if (File.Exists(src))
            File.Copy(src, Unique(Path.Combine(Paths.Shelf, Path.GetFileName(src))));
        else if (Directory.Exists(src))
            CopyDir(src, Unique(Path.Combine(Paths.Shelf, Path.GetFileName(src.TrimEnd('\\')))));
    }

    private static void CopyDir(string src, string dst)
    {
        Directory.CreateDirectory(dst);
        foreach (var f in Directory.GetFiles(src)) File.Copy(f, Path.Combine(dst, Path.GetFileName(f)));
        foreach (var d in Directory.GetDirectories(src)) CopyDir(d, Path.Combine(dst, Path.GetFileName(d)));
    }

    private static string Unique(string path)
    {
        if (!File.Exists(path) && !Directory.Exists(path)) return path;

                if (_cotacoes.TryGetValue(codigo, out var c))
                {
                    var valor = Ui.Text(c.Valor.ToString(codigo == "BTCBRL" ? "C0" : "C3", Br), 13, FontWeights.Bold);
                    Grid.SetColumn(valor, 1);
                    g.Children.Add(valor);
                    var variacao = Ui.Text($"{(c.Variacao >= 0 ? "▲" : "▼")} {Math.Abs(c.Variacao).ToString("0.00", Br)}%", 11, FontWeights.SemiBold,
                        c.Variacao >= 0 ? NotchTheme.Green : NotchTheme.Red);
                    variacao.HorizontalAlignment = HorizontalAlignment.Right;
                    Grid.SetColumn(variacao, 2);
                    g.Children.Add(variacao);
                }
                linhas.Children.Add(g);
            }
            status.Text = _status;
        }

        var botao = Ui.Button(Glyphs.Refresh, "Atualizar", () => _ = AtualizarAsync());
        var rodape = new Grid { Margin = new Thickness(0, 4, 0, 0) };
        rodape.Children.Add(status);
        botao.HorizontalAlignment = HorizontalAlignment.Right;
        rodape.Children.Add(botao);

        var root = new Grid();
        root.RowDefinitions.Add(new RowDefinition());
        root.RowDefinitions.Add(new RowDefinition { Height = GridLength.Auto });
        root.Children.Add(linhas);
        Grid.SetRow(rodape, 1);
        root.Children.Add(rodape);

        Atualizou += Render;
        Render();
        return root;
    }
